# 🌐 Life OS | Personal Optimization Hub

A centralized, web-based dashboard designed to streamline daily routines, track strategic goals, and manage personal growth metrics. This "Life Operating System" acts as a single source of truth for productivity and habit engineering.

---

## 🚀 Overview
Life OS is a modular workspace built to bridge the gap between high-level vision and daily execution. It features a custom onboarding flow to calibrate the system based on current priorities, ranging from technical automation to fitness and business strategy.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3 (Custom Grid/Flexbox layouts)
*   **Logic:** Vanilla JavaScript (ES6+)
*   **Version Control:** Git / GitHub

## 📂 Core Architecture
*   `index.html`: The structural backbone containing the Onboarding Wizard and Dashboard modules.
*   `style.css`: Modern, dark-themed UI system optimized for focus.
*   `script.js`: Functional logic for data injection and contextual task rendering.

## ⚙️ Features
- **Onboarding Engine:** Tailors the dashboard view based on user focus areas.
- **Dynamic Sprint Tracking:** Automatically generates tasks based on the "Primary Strategic Focus."
- **Metric Monitoring:** Visualizes daily wake/sleep schedules and personal mantras.
